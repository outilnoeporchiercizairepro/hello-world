# tablerondeia.prcz.fr

Page du prompt « audit du temps » offert aux dirigeants de la table ronde IA du 30/10/2026.
Le visiteur copie le prompt, le colle dans son IA, puis envoie le mail rédigé par l'IA à noe@prcz.fr pour recevoir son plan d'action.

- `index.html` : la page, autonome. Le prompt affiché est aussi la source du bouton « Copier ».
- `assets/styles.css` : copie du design system de lecockpit-business.fr.
- Déploiement : GitHub Pages via `.github/workflows/`, à chaque push sur `main`.
